# LOST-AND-FOUND

Aplicação de Achados e Perdidos desenvolvida em Java com Spring Boot para a disciplina de POO II do curso de Engenharia de Software da FANS.

O projeto Gradle e os fontes Spring Boot ficam na raiz deste repositório.

## Requisitos

- JDK 17 ou superior
- Gradle instalado
- PostgreSQL local configurado conforme `src/main/resources/application.properties`

## Executar

Na raiz do repositório, execute:

```powershell
gradle bootRun
```

Para executar os testes:

```powershell
gradle test
```
